# NarrativeLab

NarrativeLab is a simple crypto narrative generator.

It helps creators, influencers, and founders turn ideas into:
- Token concepts
- Project narratives
- Launch stories
- Tweet threads

---

## What it does (MVP)

Right now NarrativeLab is in early stage:

- Input: idea (keyword or concept)
- Output: crypto narrative + token style branding

Example:
Input: AI + memes  
Output:
- Token name: MemeMind
- Narrative: AI-powered meme economy
- Tagline: "Where memes become assets"
